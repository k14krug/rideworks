Designer notes / reusable RideWorks visual language

Approved Activity Review patterns applied as a proposal: compact page header, ink/blue/teal palette, 14px cards, 18–24px padding, carefully ranked panels, readable charts and collapsible data evidence. Dashboard proposal emphasizes the next ride and recent activities, with Training State and Performance alongside. No changes to real recommendation logic, source calculations, FTP or page routes are implied. Retain current RideWorks navigation and responsive chart controls in implementation. No global redesign until separately approved.
