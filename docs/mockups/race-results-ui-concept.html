Import steps

1. Upload your Zwift Racing Profile screenshot.

2. Check extracted dates, groups, watts and scores.

3. Confirm that each result matches an existing RideWorks ride.

4. Save only approved linked results.

Unmatched results stay pending or are skipped. Importing a screenshot never creates a new activity.
