## 4. Numerical and evidence contract

1. **Elapsed clock.** Use the same admitted source's absolute start and elapsed duration (native session start/total elapsed; or the compatible current API summary start/elapsed with validated stream offsets). Require a finite positive duration and unambiguous source clock; cross-check API start against its paired stream evidence and reject contradictory or unusable bounds rather than borrowing moving time, the last observation or another source's metadata. Bound the domain to `[0,T)` and preserve source precision at the exact endpoint, including a fractional final second if supplied. Use source elapsed 1 Hz offsets; each valid timestamp at second `s` contributes to `[s,s+1)`, clipped at `T`. A timestamp exactly at `T` adds no interval; never add a second to include it. A missing/null sample is not zero evidence; a valid recorded 0 W is observed. Non-null invalid watts, unplaceable timestamps, duplicate/backward or non-1-Hz-aligned timestamps (except the exact terminal boundary), or out-of-domain observations make the candidate unsupported for this method; retain a reason, do not sort/resample/guess. Missing seconds in an otherwise valid ordered lattice are allowed. Do not conflate these elapsed bins with strict PC-01 observed-record endpoints.
2. **Known pause.** A native stop-to-next-start interval qualifies only when bracketed by paired, whole-session-verified timer evidence from the same extraction (`timer_scope` verified), with usable second-aligned boundaries inside the elapsed domain and no valid positive recorded power strictly inside the interval. Use `[stop,resume)`: zero for its elapsed seconds, resume sample belongs to resumed riding. A record exactly at the stop is a boundary observation and contributes no power forward into the pause; the strict method still handles it as before. A positive record inside invalidates that pause claim; use observed watts where available and classify remaining holes as unknown. Record timer quality/conflict and reasons. Mere pairing, timestamp gaps, zero speed/cadence, moving/elapsed difference, or time before first/after last record or timer event is not pause evidence. No pause inference from API offsets alone.
3. **Single-second repair.** Only a maximal hole of exactly one full non-pause second with immediate valid observed neighbors on both sides in the same uninterrupted non-pause section of the same source is eligible. Use the arithmetic mean of the two neighbors, without rounding; mark the repaired second estimated. No edge, cross-pause, chained or multi-second interpolation.
4. **Other unknowns and eligibility.** Count all other missing time as unknown; for an eligible window only, use zero watts for that time in its numerator while retaining it in the elapsed denominator. Require positive observed time and **at least 95% observed coverage of non-pause time** in each candidate window: observed / (elapsed duration minus confirmed pause) ≥ 0.95. Estimated seconds do not count as observed; confirmed pause is not penalized as missing. The threshold applies to each window, not only the ride; no separate gap-length cutoff in this version. Mark unknown-zero windows as such, not measured zero; this may understate watts. A materially incomplete ride can still supply supported shorter windows. If the full window fails, apply §4.7 before showing the full endpoint as unavailable. If neither endpoint qualifies, show its elapsed duration with an explicit unavailable reason and coverage if known; do not invent or extrapolate a wattage. Distinguish missing elapsed timing, absent/ineligible power, source ambiguity, and stale/pending profile where applicable.
5. **Best at each duration.** Evaluate the existing regular duration grid up to source elapsed duration, plus the actual elapsed endpoint, deduplicated by exact duration. Evaluate every elapsed-second-aligned start for each integer grid duration that fits; for the full-duration anchor evaluate exactly `[0,T)`, weighting any partial final second by its duration. Average is summed watt-seconds / elapsed seconds. Select the maximum eligible unrounded result, breaking exact within-source ties by earliest elapsed start. Retain PC-01 ambiguity handling across competing native candidates, not highest-source-wins. The 100-minute point for a 100-minute activity is calculated even if 100 minutes is not a grid anchor. No output beyond T, invented hover values or curve connections across unsupported evaluated anchors. Do not force a monotone curve.
6. **Per-effort evidence.** Persist/reproduce method and grid versions, source and extraction/stream identity, elapsed start/end-exclusive offsets and absolute times where supported, duration, unrounded watts, observed seconds and observed/non-pause coverage, confirmed pause seconds, interpolated seconds and unknown-zero seconds, and timer/quality flags. Four disjoint time buckets sum to the actual duration; zero observed watts still counts as observed. Preserve actual observed evidence and mark assumptions as calculation-only. Do not express imputed or paused time as source record indices.

7. **Recorded-power minimum, selected ride only.** If the standard full-duration anchor fails solely on observed coverage, evaluate exactly `[0,T)` with the same admitted source and elapsed clock. Require **90% ≤ observed non-pause coverage < 95%** using unrounded coverage, positive observed time and the same source/ambiguity rules. Divide only the observed watt-seconds by T; all unobserved seconds contribute no recorded work, including any otherwise repairable second. Do not use interpolation in this fallback. Store it as a distinct versioned endpoint result with the same source/time evidence; its interpolated seconds are zero and its unknown seconds include the unfilled repairable second. This is a minimum under the method's nonnegative-power and sampling conventions, not a claim that missing watts were zero. Show an inspectable, visually distinct marker at T, not connected to the standard line, with wording such as **Full ride — recorded-power minimum** and coverage plus missing duration. Explain that unrecorded power could raise the full-ride average. Never use this marker in an overlay, historical maximum or Performance metric, even if T is on the regular grid. A source/timing failure, ambiguity, or coverage below 90% cannot use the fallback. At 95% or above, show only the standard endpoint. Cache and invalidate this result with the elapsed profile; do not treat it as a standard curve point.
