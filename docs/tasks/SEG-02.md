Same normalized paste batch is idempotent (ignore formatting noise; preserve multiplicity within a batch); overlapping batches use stable evidence, not rank or position. Do not silently merge a possible overlap or make the user inspect every row. Put only uncertain overlaps in an exception group, default to leaving those rows unimported with an explicit count, and let the user keep separate or confirm an already-saved match. For rows without a ride ID, a date and duration match is only a candidate; preserve genuinely distinct same-ride attempts and provenance. Apply the same no-silent-merge rule when Sync later supplies an exact effort; avoid counting known confirmed matches twice. Show saved count, source, best saved time, and no complete-history claim.
