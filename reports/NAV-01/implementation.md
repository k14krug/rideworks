# NAV-01 implementation and verification

## Navigation

The shared sidebar now groups two links under Power. Before this change, `/performance` loaded the 20-minute history and an in-page button switched to the Power Curve; `/performance?curve=1` opened the curve through JavaScript. Those same URLs now select the respective view and current sidebar link on the server, including on direct load and reload. The redundant in-page buttons were removed. Following Owner feedback, Power is a native disclosure that starts closed; clicking or using the keyboard reveals the two choices. Its open/closed state is retained within the browser tab when navigating or reloading, when session storage is available. The disclosure and links remain usable without JavaScript or storage. FTP History remains within the Power group without falsely marking either child as the current page.

Within the Performance page, normal sidebar clicks update the URL and view while retaining the existing history and comparison selections; browser back/forward changes the current view. Links remain usable as ordinary links, including without JavaScript. The desktop sidebar can scroll when the viewport is too short to fit all links. No chart math, source policy, data, Activity Review curve or other Home content was changed.
